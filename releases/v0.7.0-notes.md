# InstaFind — بحث سريع 0.7.0

## جديد: نسخ لأجهزة ARM64 و32 بت
- **نسخة أصلية لأجهزة ARM64** (مثل الحواسيب بمعالجات Snapdragon): `bahth-arm64.exe`، تعمل مباشرة دون محاكاة فتكون أسرع وأقل استهلاكاً للبطارية.
- **نسخة لويندوز 32 بت**: `bahth-x86.exe`.
- نسخة 64 بت العادية تبقى `bahth.exe` كما هي. كل نسخة تحدّث نفسها تلقائياً بنسختها، وScoop وwinget يختاران النسخة المناسبة لجهازك وحدهما.
- كل نسخة تُشغَّل فعلياً على ويندوز بمعالجها قبل النشر (ومنها جهاز ARM حقيقي).

## جديد: أرسل ملاحظتك بسهولة
- **«خيارات ← أرسل ملاحظة»**: ثلاثة خيارات تفتح صفحة GitHub جاهزة في المتصفح، فيها رقم الإصدار ونظام ويندوز ونوع المعالج مسبقاً: «أبلغ عن مشكلة»، «اقترح ميزة جديدة»، «اسأل أو ناقش مع المستخدمين».
- **تقارير الأخطاء باختيارك**: إن حدث خطأ داخلي، يسألك البرنامج مرة واحدة عند التشغيل التالي إن كنت تريد إرسال التقرير. «نعم» تفتح صفحة GitHub فيها التقرير لتراجعها وتضغط «Submit» بنفسك، واسم المستخدم في المسارات يُخفى. لا يُرسل البرنامج أي شيء تلقائياً، ولا يجمع أي بيانات استخدام.

**English:** New native builds for Windows on ARM64 (`bahth-arm64.exe`) and 32-bit Windows (`bahth-x86.exe`); the x64 build stays `bahth.exe`, and each build updates itself with its own. New **Options → Send feedback** (report a problem, suggest a feature, ask or discuss, each prefilled with version, Windows and processor) and opt-in crash reports: after an internal error the next start asks once, and "Yes" opens a prefilled GitHub issue for you to review and submit. Nothing is sent automatically and no usage data is collected.
