# InstaFind — بحث سريع 0.2.0

## جديد
- أيقونة جديدة، وقائمة نتائج بنمط مستكشف ويندوز مع أيقونات أنواع الملفات.
- فلاتر أنواع جاهزة: مستندات، صور، صوت، فيديو، مضغوطات، برامج، مجلدات.
- تصحيح الكتابة بلوحة المفاتيح الخطأ: `hgjrvdv` تعرض نتائج «التقرير».
- تجاهل «ال»: «التقرير» تجد «تقرير.pdf»، وتوحيد الحروف الفارسية وأشكال العرض العربية.
- عوامل البحث: `صورة|فيديو`، و`!قديم`، و`مجلد:`، و`ext:jpg;png`.
- تصدير النتائج إلى CSV يفتحه Excel بالعربية.
- فتح فوري، ونسخة واحدة، وأيقونة في شريط المهام، وتواريخ نسبية، وخيار الأرقام العربية.

**English:** New icon, Explorer-style results with file-type icons, type filters, wrong-keyboard-layout correction, `ال`-insensitive matching, OR / NOT / folder / extension operators, CSV export, tray icon and single instance.
