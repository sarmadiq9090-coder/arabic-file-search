# InstaFind — بحث سريع 0.10.0: جرّب الشكل الجديد، وإصلاح أمني لملفات Excel

- **جرّب الشكل الجديد (اختياري)**: «خيارات ← جرّب الشكل الجديد» يفتح الواجهة الجديدة فوراً، و«العودة إلى الشكل القديم» يرجعك متى شئت. الشكل المعتاد يبقى الافتراضي، وإن تعذّر تشغيل الشكل الجديد يعود البرنامج إلى المعتاد تلقائياً. يحتاج WebView2 (موجود في ويندوز 11 وأغلب أجهزة ويندوز 10)، والخيار يظهر فقط حيث يتوفر.
- **إصلاح أمني**: تحديث مكتبة قراءة Excel (calamine 0.38) لسدّ ثغرة RUSTSEC-2026-0436 في ملفات ‎.xls و‎.xlsb التي يفتحها الفهرس تلقائياً.
- **أسماء الملفات العربية**: الامتداد يظهر كاملاً في نهاية الاسم، والمسارات تبقى باتجاهها الصحيح داخل الواجهة العربية، ونافذة البحث الصغيرة ترسم نقاط الياء الأخيرة.
- **تنبيه OCR**: إذا غابت حزمة اللغة العربية لقراءة الصور يخبرك البرنامج بدل تخطّي النص بصمت.
- **الدعم**: «خيارات ← الدعم» يفتح البريد support@fastkiwi.app أو صفحة الدعم.
- **إسناد أسعار الصرف** تحت كل جواب لتحويل العملات.
- **الرخصة**: InstaFind مجاني للاستخدام كما كان، وصار برنامجاً مملوكاً ابتداءً من هذا الإصدار؛ الإصدارات حتى 0.9.1 تبقى برخصة MIT.
- **البناء**: ملفات x64 و32-بت تُبنى الآن بـ MSVC مع مكتبات مضمّنة، فلا تحتاج أي تثبيت إضافي.

**English:** Opt-in new look (Options › Try the new look; classic stays the default, one click back, automatic fallback to classic if WebView2 fails). Security: calamine 0.38 fixes RUSTSEC-2026-0436 in legacy Excel files read by the indexer. Arabic file names show the extension whole at the end; paths stay left-to-right inside Arabic text; the quick-search popup no longer clips dots under the line. A notice when the Arabic OCR language pack is missing. Support entry in Options. Exchange-rate attribution. Licence: InstaFind stays free to use and is proprietary from this version on; versions up to 0.9.1 remain MIT. The x64 and 32-bit exes are now built with MSVC and a static CRT. The Store rating prompt exists only in the Microsoft Store package.
