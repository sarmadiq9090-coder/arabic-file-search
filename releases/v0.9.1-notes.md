# InstaFind — بحث سريع 0.9.1: تحديث أمني

- **لا تحديث بدون تحقق**: إذا لم يجد البرنامج بصمة SHA-256 لملف التحديث على GitHub، يرفض التحديث ويعرض رابط التنزيل اليدوي.
- **نسخ winget و Scoop** تُترك لمدير الحزم: يعرض البرنامج أمر التحديث بدل أن يحدّث نفسه.

**English:** Security update. The updater now refuses an update when GitHub publishes no SHA-256 digest for the program file (previously it could install without verification) and shows the manual download link instead. Copies installed with winget or Scoop no longer update themselves; they show the package manager's update command.
