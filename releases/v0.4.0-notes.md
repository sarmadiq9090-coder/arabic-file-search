# InstaFind — بحث سريع 0.4.0

## جديد
- **البحث بالحجم**: `حجم:>10م`، `size:1mb..5mb`، `حجم:كبير`.
- **البحث بتاريخ التعديل**: `تاريخ:اليوم`، `تاريخ:أمس`، `dm:thisweek`، `dm:2024-05`، `dm:7d`.
- **تعبيرات منتظمة** `regex:` و**الكلمة كاملة** `كلمة:`، و**البحث بالتقارب** `"عقد إيجار"~5`.
- **كل التطابقات داخل الملف**: عددها في عمود النص المطابق، وF4 يعرض الأسطر المطابقة.
- **سطر الأوامر**: `bahth.exe -s "فاتورة ext:pdf"` مع `--csv` و`--json` و`--count`.
- تنبيه عند كتابة صيغة بحث غير مفهومة، وإعادة تشغيل أكثر أماناً بعد التحديث التلقائي.

**English:** Size and date filters, regex, whole word, proximity search, all matches per document (F4), and a command line (`bahth.exe -s`).
