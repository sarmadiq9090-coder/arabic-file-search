Features

Everything you need to find your files

Written in Rust. The index keeps itself current as files are added, deleted or renamed.

Arabic search that understands how people type

Hamza forms, ta marbuta, alef maqsura, diacritics, tatweel and the ال prefix are ignored, and Arabic-Indic digits are accepted. When nothing matches, it retries with the other keyboard layout, then Arabizi, then near spellings.

Inside documents

PDF, Word, Excel, PowerPoint, e-mail and epub, with a snippet of the matching text. Images and scanned PDFs too, through the OCR engine built into Windows, and archives without extracting them.

Instant filename search

Across all drives or one folder, with ready-made filters for documents, pictures, video and more. Often-opened files come first.

Rich query syntax

Phrases, OR, NOT, extensions, size, date modified, regex and word proximity, e.g. ext:pdf size:>10mb dm:thismonth.

Handy tools

Duplicate finder, folder sizes, thumbnails, find & replace across text files with undo, CSV export, and drag & drop into WhatsApp or mail.

Clean results

System files and temp folders are hidden by default, so you only see your own files. Show them with one option, or type system:.

English or Arabic

The interface follows your Windows language and can be switched any time. It starts with Windows in the background and updates itself with one click.

Content search

Search inside PDF, Word and more

Tick Also search inside documents and press Enter: every file that contains your words is listed. Size and date filters work here too.

  • Persistent content index: each document's text is extracted once in the background, so later searches are near-instant.
  • Images and scanned PDFs through the OCR engine built into Windows, with no download.
  • Reversed Arabic text in PDFs is repaired, and F4 lists every match in a file with line numbers.

FAQ

Frequently asked questions

Is InstaFind free?

Yes. It is free and open source under the MIT license.

Can it search inside PDF and Word files?

Yes. Tick Also search inside documents and press Enter. It reads docx, xlsx, xls, pptx, pdf, odt, ods, rtf, doc, txt, csv, e-mail (eml, msg), epub and source code, and repairs reversed Arabic text in PDFs. Images and scanned PDFs are read with the OCR engine built into Windows 10 and 11.

Is it an alternative to Everything?

If you want instant filename search across all drives, like Everything, plus real Arabic matching and search inside documents, that is what InstaFind is built for.

Does it need an internet connection?

No. Indexing and search run on your PC. The only connection is the update check against GitHub.

What are the requirements?

Windows 10 or 11, 64-bit. Text recognition in images needs the Windows language pack for each OCR language.

Does it run on ARM or 32-bit Windows?

Not natively yet. ARM64 and 32-bit builds are coming in version 0.7. The current release is for 64-bit (x64) Windows 10 or 11, and it also runs on Windows 11 on ARM through emulation.

Why does SmartScreen warn me?

Because the file is not code-signed. Click More info, then Run anyway. All the source code is on GitHub.

How do I uninstall it?

Turn off Start with Windows in Options…, then delete bahth.exe and the %LOCALAPPDATA%\BahthSari\ folder.
