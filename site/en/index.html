Everything you need to find your files

A file search tool for Windows written in Rust. The index keeps itself current as files are added, deleted or renamed.

Instant filename search

Across all drives or one folder, with ready-made filters: documents, pictures, audio, video, archives, programs, folders. Often-opened files come first.

Inside documents

PDF, Word, Excel, PowerPoint, e-mail and epub, with a snippet of the matching text. Images and archives too.

Rich query syntax

Phrases, OR, NOT, extensions, size, date modified, regex, whole word and word proximity, e.g. ext:pdf size:>10mb dm:thismonth.

From anywhere

Ctrl+Alt+F shows the app from anywhere; Ctrl+Alt+G in any program's Save or Open dialog jumps the dialog to the folder of a result.

Handy tools

Duplicate finder, folder sizes, thumbnail view, find & replace in text files with undo, CSV export, drag & drop into WhatsApp or mail, a command line and a Flow Launcher plugin.

English or Arabic interface

Follows the Windows display language; switch any time in Options → Language / اللغة. Starts with Windows in the background and updates itself with one click.

Arabic file search that understands how people type

Hamza forms, ta marbuta, alef maqsura, diacritics, tatweel and the ال prefix are ignored; Arabic-Indic digits and Persian letters are accepted. When nothing matches, it retries with the other keyboard layout, then Arabizi, then near spellings.

  • احمد→أحمدHamza forms don't matter
  • التقرير→تقرير.pdfThe ال prefix doesn't block a match
  • hgjrvdv→التقريرTyped on the wrong keyboard layout? Still found
  • 3abd→عبدArabizi (Franco-Arabic) is read as Arabic
  • fuzzy: reprot→reportTolerates one or two typos
  • root: كتاب→مكتبة، الكاتب، كتاباتWords sharing the Arabic root

Your files stay on your PC

Searching with InstaFind works offline. Your files and their index stay on your computer; none of it is uploaded anywhere.

  • The only internet connections are the daily update check against GitHub and the exchange-rate download for currency conversion, about every 12 hours.
  • Search from your phone over the home network is off by default; when on, it is PIN-protected and read-only.
  • No telemetry. Feedback and crash reports are optional and reach GitHub only when you press Submit yourself.
  • Its data lives in %LOCALAPPDATA%\BahthSari\ and can be deleted at any time.

Frequently asked questions

Is InstaFind free?

Yes. It is free to use on your own devices.

Can it search inside PDF and Word files?

Yes. Tick Also search inside documents and press Enter. It reads docx, xlsx, xls, pptx, pdf, odt, ods, rtf, doc, txt, csv, e-mail (eml, msg), epub and source code, and repairs reversed Arabic text in PDFs. Images and scanned PDFs are read with the OCR engine built into Windows 10 and 11.

Is it an alternative to Everything?

If you want instant filename search across all drives, like Everything, plus real Arabic matching and search inside documents, that is what InstaFind is built for.

Does it need an internet connection?

No. Indexing and search run on your PC. The only connections are the update check against GitHub and the exchange-rate download for currency conversion, about every 12 hours.

What are the requirements?

Windows 10 or 11, 64-bit. Text recognition in images needs the Windows language pack for each OCR language.

Why does SmartScreen warn me?

Because the file is not code-signed. Click More info, then Run anyway. Every release is published on GitHub.

How do I uninstall it?

Turn off Start with Windows in Options…, then delete bahth.exe and the %LOCALAPPDATA%\BahthSari\ folder.
