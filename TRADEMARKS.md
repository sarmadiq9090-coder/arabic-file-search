## Official download sources

Only these are official:

- **GitHub Releases** of this repository:
  <https://github.com/sarmadiq9090-coder/arabic-file-search/releases> (`bahth.exe`,
  `bahth-x86.exe`, `bahth-arm64.exe`). The app's built-in updater downloads only from here.
- **Website**: <https://fastkiwi.app/arabic-file-search/>
- **Scoop**, from the bucket in this repository:
  `scoop bucket add instafind https://github.com/sarmadiq9090-coder/arabic-file-search`, then
  `scoop install instafind`.
- **winget**: `Sarmad.InstaFind`, once it is accepted into
  [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs).
- **Chocolatey**: `instafind`, once it is published on the Chocolatey Community Repository.
- **Microsoft Store**: once it is listed; the listing will be linked from the website and the
  README.

A copy from anywhere else is not official, even if it uses the InstaFind name or icon.

## Reporting impersonation

If you find a copy that uses the InstaFind or FastKiwi name or icon and pretends to be official,
please tell us:

- open an issue: <https://github.com/sarmadiq9090-coder/arabic-file-search/issues/new>, or
- use the support page: <https://fastkiwi.app/support/>.

Include the link and, if you can, a screenshot.
